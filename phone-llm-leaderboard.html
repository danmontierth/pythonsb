The Dwarf Star range (128 GB). DeepSeek V4 Flash is a 284B-parameter MoE (13B active) that normally needs ~568 GB — but DwarfStar 4 (ds4), the inference engine by Salvatore “antirez” Sanfilippo (creator of Redis), squeezes it to ~81 GB with asymmetric 2-bit/8-bit selective quantization. Result: near-frontier intelligence (index 37) running locally on a 128 GB MacBook M4 Max or NVIDIA DGX Spark, with 250K-token context demonstrated even on 96 GB.

Notes. Scores are the Artificial Analysis Intelligence Index (v4.x agentic-weighted scale, July 13 2026 snapshot — frontier scores were rebased down ~5 points from the older index version this week); values marked ~ are estimates interpolated from adjacent published results, since sources disagree across snapshots and reasoning modes. Min RAM is the approximate unified memory to run a ~4-bit quant with usable context. Frontier models are API-only, so their memory footprint is unpublished — they live in the Cloud zone. $/1M tok is the blended API price (3:1 input:output); for open models it’s the typical hosted rate, and Index/$ divides the intelligence index by that price — the value metric behind the “Score ÷ cost” sort.
